## 🔧 Если что-то не работает:

### Приложение не загружается

1. Проверьте что Backend запущен:
   ```bash
   curl http://localhost:8080/health
   ```

2. Проверьте IP адрес в `mobile/app.json`:
   ```json
   "extra": {
     "apiUrl": "http://192.168.1.109:8080/api/v1",
     "wsUrl": "ws://192.168.1.109:8080/api/v1/ws"
   }
   ```

3. Убедитесь что iPhone и ПК **в одной WiFi сети**

### Metro показывает ошибки

Очистите кеш и перезапустите:
```bash
cd mobile
rm -rf .expo node_modules/.cache
npm start -- --clear
```

### "Cannot connect" в Expo Go

1. Проверьте firewall Windows (разрешите порт 8081)
2. Попробуйте tunnel mode:
   ```bash
   npx expo start --tunnel
   ```
