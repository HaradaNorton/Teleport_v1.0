# 🧪 Teleport Testing Guide

## Тестирование функции "Создание новых чатов"

### Подготовка

1. Запустите backend:
```bash
cd backend
go run cmd/api/main.go
```

2. Запустите mobile приложение:
```bash
cd mobile
npx expo start
```

3. **ВАЖНО:** Если backend на вашем компьютере, а приложение на iPhone, обновите IP адрес:
   - Откройте `mobile/src/services/api.ts`
   - Замените `localhost` на IP вашего компьютера

## Частые проблемы

### "Cannot connect to backend"

**Решение:**
- Убедитесь что backend запущен
- Проверьте IP адрес в `api.ts`
- Компьютер и iPhone в одной сети

### "User not found"

**Решение:**
- Пользователь должен сначала зарегистрироваться
- Проверьте что номер телефона правильный

### "Chat already exists"

**Решение:**
- Это нормально! Backend не создает дубликаты
- Приложение откроет существующий чат

### Пустой список в поиске

**Решение:**
- Введите минимум 2 символа
- Проверьте регистр (поиск case-insensitive)

## Тестирование функции "Групповые чаты"

### Шаг 1: Создание группового чата

**Предварительно:** Создайте 3+ пользователя (Alice, Bob, Charlie)

1. В ChatListScreen нажмите **"New Group"** в header
2. Введите название группы: "Test Group"
3. Введите в поиск "Alice" и выберите пользователя
4. Введите в поиск "Bob" и выберите пользователя
5. Нажмите **"Create Group (2)"**

**Ожидаемый результат:**
- ✅ Группа создана
- ✅ Автоматический переход в чат группы
- ✅ В header видна кнопка **"Info"**
- ✅ Название группы отображается в header

---

### Шаг 2: Отправка сообщений в группе

1. Отправьте сообщение: "Hello everyone!"
2. Выйдите из группы и войдите как Alice
3. Откройте группу из списка чатов
4. Проверьте, что видно сообщение от создателя (Charlie)
5. Отправьте ответ: "Hi from Alice"

**Ожидаемый результат:**
- ✅ Сообщения от других пользователей показывают имя отправителя
- ✅ Ваши сообщения НЕ показывают имя (выровнены справа)
- ✅ Все сообщения видны всем участникам

---

### Шаг 3: Просмотр информации о группе

1. В групповом чате нажмите **"Info"** в header
2. Проверьте отображение:
   - Название группы
   - Количество участников
   - Список всех участников с ролями

**Ожидаемый результат:**
- ✅ Создатель группы имеет роль "👑 Owner"
- ✅ Остальные участники имеют роль "Member"
- ✅ Видна кнопка **"+ Add"** (для owner/admin)
- ✅ Видна кнопка **"Edit"** рядом с названием (для owner/admin)

---

### Шаг 4: Редактирование названия группы

**Только для Owner/Admin:**

1. В GroupInfoScreen нажмите **"Edit"** под названием
2. Измените название на "Updated Group Name"
3. Нажмите **"Save"**

**Ожидаемый результат:**
- ✅ Название обновлено
- ✅ Alert "Success, Group name updated"
- ✅ Новое название видно в GroupInfoScreen
- ✅ Новое название видно в ChatScreen header

---

### Шаг 5: Добавление участника

**Только для Owner/Admin:**

1. В GroupInfoScreen нажмите **"+ Add"**
2. Введите в поиск имя нового пользователя (например, "David")
3. Нажмите на пользователя

**Ожидаемый результат:**
- ✅ Alert "Success, [User] added to group"
- ✅ Автоматический возврат в GroupInfoScreen
- ✅ Новый участник виден в списке членов
- ✅ Новый участник может видеть группу и все сообщения

---

### Шаг 6: Повышение до Admin (Promote)

**Только для Owner:**

1. В списке участников найдите обычного Member
2. Нажмите кнопку **"Promote"**
3. Подтвердите в диалоге

**Ожидаемый результат:**
- ✅ Роль изменена на "⭐ Admin"
- ✅ Alert "Success, Role updated"
- ✅ Обновленная роль видна в списке
- ✅ Admin теперь может добавлять/удалять участников
- ✅ Admin НЕ может изменять роли (только Owner)

---

### Шаг 7: Понижение Admin (Demote)

**Только для Owner:**

1. Найдите участника с ролью Admin
2. Нажмите кнопку **"Demote"**
3. Подтвердите в диалоге

**Ожидаемый результат:**
- ✅ Роль изменена обратно на "Member"
- ✅ Alert "Success, Role updated"

---

### Шаг 8: Удаление участника

**Только для Owner/Admin:**

1. Найдите обычного участника (Member)
2. Нажмите кнопку **"Remove"**
3. Подтвердите удаление

**Ожидаемый результат:**
- ✅ Alert "Success, Member removed"
- ✅ Участник исчез из списка
- ✅ Удаленный пользователь больше не видит группу в своем списке
- ✅ НЕЛЬЗЯ удалить Owner (ошибка "Cannot remove group owner")

---

### Шаг 9: Выход из группы

**НЕ для Owner:**

1. Войдите как обычный участник (не Owner)
2. Откройте GroupInfoScreen
3. Прокрутите вниз и нажмите **"Leave Group"**
4. Подтвердите выход

**Ожидаемый результат:**
- ✅ Alert "Success, You left the group"
- ✅ Автоматический переход в ChatListScreen
- ✅ Группа исчезла из списка чатов
- ✅ Если зайти как Owner, видно что участник удален

**Попытка выхода Owner:**
1. Войдите как Owner
2. Попробуйте выйти из группы

**Ожидаемый результат:**
- ✅ Alert "Error, Owner cannot leave group. Transfer ownership first."

---

### Шаг 10: Проверка прав доступа

**Проверьте для обычного Member:**

1. Войдите как обычный участник
2. Откройте GroupInfoScreen
3. Проверьте что НЕТ кнопок:
   - **"Edit"** (редактирование названия)
   - **"+ Add"** (добавление участников)
   - **"Promote"/"Demote"** (изменение ролей)
   - **"Remove"** (удаление участников)
4. ЕСТЬ только кнопка **"Leave Group"**

**Проверьте для Admin:**

1. Войдите как Admin
2. Откройте GroupInfoScreen
3. Проверьте что ЕСТЬ кнопки:
   - **"Edit"** (редактирование названия)
   - **"+ Add"** (добавление участников)
   - **"Remove"** (удаление участников)
4. НЕТ кнопок **"Promote"/"Demote"** (только для Owner)

**Проверьте для Owner:**

1. Войдите как Owner
2. ЕСТЬ ВСЕ кнопки управления

## API тестирование медиа (через Postman)

### 1. Загрузка файла

```http
POST http://localhost:8080/api/v1/media/upload
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: multipart/form-data

Body (form-data):
- file: [выберите файл]
```

**Response:**
```json
{
  "media_url": "/api/v1/media/files/images/uuid.jpg",
  "thumbnail_url": "/api/v1/media/files/thumbnails/uuid.jpg",
  "file_name": "image.jpg",
  "mime_type": "image/jpeg",
  "file_size": 123456,
  "media_type": "image"
}
```
