# 🧪 Teleport Testing Guide

## Тестирование функции "Создание новых чатов"

### Подготовка

1. Запустите backend:
```bash
cd backend
go run cmd/api/main.go
```

2. Запустите mobile приложение:
```bash
cd mobile
npx expo start
```

3. **ВАЖНО:** Если backend на вашем компьютере, а приложение на iPhone, обновите IP адрес:
   - Откройте `mobile/src/services/api.ts`
   - Замените `localhost` на IP вашего компьютера

---

## Сценарий тестирования

### Шаг 1: Создайте двух пользователей

**Пользователь 1:**
1. Откройте приложение на iPhone
2. Введите номер: `+79001111111`
3. Код: `12345`
4. Заполните профиль: Имя "Alice"

**Пользователь 2:**
1. Выйдите из приложения (Profile → Logout)
2. Введите номер: `+79002222222`
3. Код: `12345`
4. Заполните профиль: Имя "Bob"

---

### Шаг 2: Поиск пользователей

1. Нажмите кнопку **"New Chat"** в header ИЛИ кнопку **"+"** внизу
2. Введите в поиск: `Alice`
3. Должен появиться пользователь Alice с номером +79001111111
4. Попробуйте поиск по номеру: `+7900111`
5. Alice должна снова появиться

**Ожидаемый результат:**
- ✅ Поиск работает по имени
- ✅ Поиск работает по номеру телефона
- ✅ Текущий пользователь (Bob) НЕ появляется в результатах

---

### Шаг 3: Создание личного чата

1. Нажмите на Alice в результатах поиска
2. Приложение должно:
   - Создать новый чат
   - Перейти в этот чат
   - Показать имя "Alice" в заголовке

3. Отправьте сообщение: "Hello Alice!"

**Ожидаемый результат:**
- ✅ Чат создан
- ✅ Сообщение отправлено
- ✅ Сообщение видно в диалоге

---

### Шаг 4: Проверка списка чатов

1. Вернитесь на главный экран (кнопка назад)
2. Чат с Alice должен появиться в списке

**Ожидаемый результат:**
- ✅ Чат виден в списке
- ✅ Показывается последнее сообщение
- ✅ FAB кнопка "+" видна внизу экрана

---

### Шаг 5: Переключение пользователей

1. Выйдите из приложения (Profile → Logout)
2. Войдите как Alice (`+79001111111`, код `12345`)
3. Проверьте список чатов

**Ожидаемый результат:**
- ✅ Чат с Bob виден
- ✅ Сообщение "Hello Alice!" отображается
- ✅ Unread count = 1

4. Откройте чат с Bob
5. Отправьте ответ: "Hi Bob!"

**Ожидаемый результат:**
- ✅ Сообщение отправлено
- ✅ Unread count сбросился

---

### Шаг 6: Дублирование чатов

1. Снова нажмите "New Chat"
2. Найдите Bob
3. Нажмите на него

**Ожидаемый результат:**
- ✅ Новый чат НЕ создается
- ✅ Открывается существующий чат с Bob
- ✅ История сообщений на месте

## API тестирование (через Postman)

### 1. Регистрация пользователя

```http
POST http://localhost:8080/api/v1/auth/send-code
Content-Type: application/json

{
  "phone_number": "+79003333333"
}
```

```http
POST http://localhost:8080/api/v1/auth/verify
Content-Type: application/json

{
  "phone_number": "+79003333333",
  "code": "12345"
}
```

Сохраните `access_token` из ответа!

---

### 2. Поиск пользователей

```http
GET http://localhost:8080/api/v1/users/search?q=Alice
Authorization: Bearer YOUR_ACCESS_TOKEN
```

**Ожидаемый ответ:**
```json
{
  "users": [
    {
      "id": "...",
      "phone_number": "+79001111111",
      "name": "Alice",
      ...
    }
  ],
  "total": 1
}
```

---

### 3. Создание чата

```http
POST http://localhost:8080/api/v1/chats
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json

{
  "type": "personal",
  "user_ids": ["USER_ID_ALICE"]
}
```

**Ожидаемый ответ:**
```json
{
  "chat_id": "uuid-here"
}
```

---

### 4. Отправка сообщения

```http
POST http://localhost:8080/api/v1/chats/CHAT_ID/messages
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json

{
  "chat_id": "CHAT_ID",
  "content": "Test message",
  "type": "text"
}
```

## Частые проблемы

### "Cannot connect to backend"

**Решение:**
- Убедитесь что backend запущен
- Проверьте IP адрес в `api.ts`
- Компьютер и iPhone в одной сети

### "User not found"

**Решение:**
- Пользователь должен сначала зарегистрироваться
- Проверьте что номер телефона правильный

### "Chat already exists"

**Решение:**
- Это нормально! Backend не создает дубликаты
- Приложение откроет существующий чат

### Пустой список в поиске

**Решение:**
- Введите минимум 2 символа
- Проверьте регистр (поиск case-insensitive)
