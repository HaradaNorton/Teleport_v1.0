# 🚀 Как запустить Teleport

## Текущий статус

✅ **Backend запущен** в фоновом режиме на http://localhost:8080
✅ **Mobile (Expo)** запущен в фоновом режиме
✅ **База данных (Docker)** запущена

## Проблема

Процессы запущены в фоне, поэтому **не виден QR-код** для подключения мобильного приложения.

---

## 🎯 Решение: Используйте готовые скрипты

Я создал удобные `.bat` файлы для запуска:

### Вариант 1: Запустить всё сразу (рекомендуется)

**Двойной клик на файл:**
```
start-all.bat
```

Это откроет 2 новых окна:
1. **Backend** - Go сервер
2. **Mobile** - Expo с QR-кодом

### Вариант 2: Запустить по отдельности

**Backend:**
```
start-backend.bat
```

**Mobile (в отдельном окне):**
```
start-mobile.bat
```

### Остановка всех сервисов

```
stop-all.bat
```

---

## 📱 Как подключиться к мобильному приложению

### После запуска `start-mobile.bat`:

1. **Установите Expo Go на телефон:**
   - [Android - Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - [iOS - App Store](https://apps.apple.com/app/expo-go/id982107779)

2. **Посмотрите в окно где запущен Mobile** - там будет QR-код примерно через 30 секунд

3. **Отсканируйте QR-код:**
   - Android: Откройте Expo Go → Scan QR code
   - iOS: Откройте Камеру → наведите на QR-код

4. **Телефон и компьютер должны быть в одной WiFi сети!**

## 🔧 Альтернативные способы

### Если QR-код не работает или нет телефона:

#### 1. Веб-версия (в браузере)
```
http://localhost:19006
```

#### 2. Android Emulator
В окне Expo нажмите клавишу `a`

#### 3. Tunnel mode (через интернет)
Остановите mobile и запустите:
```bash
cd mobile
npx expo start --tunnel
```

## ❓ Проблемы и решения

### Приложение не подключается к Backend

**Проверьте IP адрес:**

1. Узнайте IP вашего компьютера:
```bash
ipconfig
```
Найдите "IPv4 Address" для WiFi адаптера

2. Если IP не `192.168.1.109`, обновите `mobile/app.json`:
```json
"extra": {
  "apiUrl": "http://ВАШ_IP:8080/api/v1",
  "wsUrl": "ws://ВАШ_IP:8080/api/v1/ws"
}
```

3. Перезапустите Mobile

### QR-код не показывается

Подождите 30-60 секунд после запуска. Если не помогло:
```bash
cd mobile
npm start -- --clear
```

### "Cannot connect to Metro"

Очистите кеш:
```bash
cd mobile
npm start -- --reset-cache
```
