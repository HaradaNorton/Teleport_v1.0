# ⚠️ Проблема с Expo Go SDK 54

## Что произошло:

Ваш Expo Go обновился до **SDK 54**, но наш проект использует **SDK 50**.

Попытка обновить проект до SDK 54 **не удалась** - слишком много breaking changes.

## ✅ Решение: 3 варианта

### 🌐 Вариант 1: Веб-версия (САМЫЙ ПРОСТОЙ!)

Запустить приложение прямо в браузере, без телефона:

1. **Закройте все консоли**
2. **Двойной клик:** `start-web.bat`
3. **Откроется браузер** с приложением
4. **Войдите с кодом:** 12345

**Плюсы:** Работает сразу, не нужен телефон
**Минусы:** Нет камеры и микрофона для звонков

---

### 📱 Вариант 2: Откатить Expo Go до SDK 50 (рекомендуется для тестов)

#### Для Android:
1. Удалите Expo Go с телефона
2. Скачайте старую версию SDK 50:
   - [APK Expo Go SDK 50](https://expo.dev/go?sdkVersion=50&platform=android&device=true)
3. Установите APK
4. Запустите `start-mobile.bat`
5. Отсканируйте QR-код

#### Для iOS:
К сожалению, на iOS нельзя установить старую версию Expo Go из-за App Store ограничений.

**Используйте веб-версию** или создайте Development Build.

---

### 🛠️ Вариант 3: Development Build (для продакшена)

Создать полноценную сборку приложения (занимает ~30-60 минут):

```bash
# Установить EAS CLI
npm install -g eas-cli

# Войти в Expo аккаунт
eas login

# Создать Development Build для Android
cd mobile
eas build --profile development --platform android --local

# После сборки установить APK на телефон
```

**Плюсы:** Полная функциональность, работает как реальное приложение
**Минусы:** Долго собирается, нужен Expo аккаунт

---

## 🚀 Рекомендация:

## 💡 Дополнительно:

### Почему не обновляемся до SDK 54?

- React Native обновился с 0.73 до 0.81 (много breaking changes)
- React обновился с 18 до 19 (новая архитектура)
- Многие пакеты несовместимы
- Нужно переписывать часть кода

### Можно ли использовать приложение без обновления?

**Да!** Используйте:
- Веб-версию (браузер)
- Старый Expo Go SDK 50 (Android)
- Development Build
